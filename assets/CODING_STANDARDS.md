# Coding Standards

Review the repository's own AGENTS.md and documentation first. Preserve its
architecture, naming, formatting, dependency, testing, and release conventions.

When project guidance is absent:

- Prefer small, behavior-focused changes.
- Add tests for changed behavior and regressions.
- Avoid unrelated refactors.
- Run the repository's documented checks before committing.
- Never commit secrets, generated credentials, or local configuration.
